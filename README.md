# Draw Chrome

Draw Chrome is a cyberpunk hack of MCDM's Draw Steel, in early prototyping. This repo is an Obsidian vault: open the folder as a vault and start from `Draw Chrome.md`.

The Claude Doc "Draw Chrome" is the source of truth. Each section of the doc is one note here, linked with wikilinks.

## Layout

- `Draw Chrome.md`: home note, links every other note.
- `Rules/`: Overview, Reskins, Conditions.
- `Character Creation/`: Character Creation, Background, Skills, Career - Sysadmin, Traits, Chrome, Street Styles, Stress.
- `Netrunner/`: Netrunner, Netrunner Tradition, Netrunning, Bandwidth, Cyberdeck, ICE, Remote Comms, Netrunner Abilities.
- `Open Questions.md`: design questions still open.
- `Sheets/`: the fillable PDF character sheet (Character and Chrome pages).

Obsidian workspace files are ignored in `.gitignore`, so only the notes and `.obsidian/app.json` are tracked.
